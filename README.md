# GovPath

GovPath is a government jobs preparation platform built with Flutter, FastAPI, PostgreSQL, and Docker.

This project scaffold follows the architecture outlined for the backend app and supporting folders.

## Structure

- backend/app - FastAPI application and business logic
- backend/tests - backend test files
- frontend - Flutter frontend
- docs - product and architecture documentation
- datasets - job/resource data imports
- scripts - data import and database seeding utilities
